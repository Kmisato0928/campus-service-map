# 长安大学校园服务地图系统 - 软件打包说明

## 背景

本项目依赖 Java 17+ 和 MySQL 8.0+，因此无法做到真正的"单文件免安装"。最实用的交付方案是使用 `jpackage --type app-image` 生成一个包含 JDK + JavaFX 运行时的目录，压缩后发送；接收方解压后需确保 MySQL 可用。

---

## 环境要求（打包机）

| 工具 | 要求 | 说明 |
|------|------|------|
| JDK | 17+ | 本机已安装 JDK 21 于 `D:\Program Files\Java\jdk-21` |
| JavaFX JMODs | 17+ | 用于 jlink/jpackage 内嵌 JavaFX 运行时 |
| Maven | 3.8+ | 本机已安装 |
| MySQL | 8.0+ | 本机或目标演示机运行 |

---

## 方案一：app-image 便携目录（推荐）

生成一个文件夹，内含 JDK + JavaFX + 应用 jar，无需安装，直接解压运行。

### 步骤 1：下载 JavaFX JMODs

从 GluonHQ 下载 JavaFX 17 JMOD 文件：
<https://gluonhq.com/products/javafx/>

选择 **JavaFX 17.0.2** → **Windows x64** → **JMODs** 链接下载。
解压后得到的文件夹路径记为 `JAVAFX_JMOD_PATH`，例如：

```
D:\javafx-jmods-17.0.2
```

### 步骤 2：编译 fat jar

```bash
# 使用 JDK 21 的 Maven 编译
"D:\Program Files\Java\jdk-21\bin\java" -version   # 确认是 JDK 21

# 先初始化数据库（如未执行过）
mysql -u root -p < docs/database/init-database.sql

# 编译 + 打包 fat jar
"D:\Program Files\Java\jdk-21\bin\javac"  # 不需要手动
# 直接用 Maven 编译
mvn clean package -DskipTests
```

执行后 `target/` 目录下会出现两个 jar：
- `campus-map-system-1.0.0.jar` - 瘦包（~140KB）
- `campus-map-system-1.0.0-fat.jar` - 胖包（~5MB，包含所有依赖）

### 步骤 3：生成 app-image

```bash
# 用 JDK 21 的 jpackage 生成便携目录
"D:\Program Files\Java\jdk-21\bin\jpackage" ^
  --type app-image ^
  --input target/ ^
  --dest package/ ^
  --name CampusMapSystem ^
  --main-jar campus-map-system-1.0.0-fat.jar ^
  --main-class edu.chd.campusmap.Main ^
  --module-path "D:\javafx-jmods-17.0.2" ^
  --add-modules javafx.controls,javafx.fxml,java.sql ^
  --win-console
```

> **`--win-console`** 参数会保留控制台窗口，方便看到日志输出；答辩演示时可以去掉此参数。

成功后 `package/CampusMapSystem/` 目录结构大致如下：

```
package/CampusMapSystem/
├── app/
│   └── campus-map-system-1.0.0-fat.jar
├── runtime/                  # 内嵌的 JDK + JavaFX
├── CampusMapSystem.exe       # 启动程序
└── CampusMapSystem.cfg       # 启动配置
```

### 步骤 4：使用方式

将 `package/CampusMapSystem/` 整个目录压缩为 zip，发送给答辩老师。

**接收方需要做的：**
1. 解压 zip 到任意目录
2. 确保 MySQL 服务已运行，且 `campus_map` 数据库已初始化
3. 编辑 `app/campus-map-system-1.0.0-fat.jar` 同级目录下的数据库配置（将 `database.properties` 放在同目录下会自动读取，见下节说明）——或者直接双击 `CampusMapSystem.exe`，如果数据库配置正确就直接运行

> **关于数据库配置：** 当前项目从 classpath 读取 `config/database.properties`。如果需要在 app-image 中修改数据库连接信息，需要将 `src/main/resources/config/database.properties` 复制到 app-image 目录的对应位置，或修改源码支持外部配置文件。

## 方案二：exe 安装包

如果确实需要生成安装包：

```bash
# 先生成 fat jar
mvn clean package -DskipTests

# 再生成 exe 安装包（需要 WiX Toolset）
"D:\Program Files\Java\jdk-21\bin\jpackage" ^
  --type exe ^
  --input target/ ^
  --dest package/ ^
  --name CampusMapSystem ^
  --main-jar campus-map-system-1.0.0-fat.jar ^
  --main-class edu.chd.campusmap.Main ^
  --module-path "D:\javafx-jmods-17.0.2" ^
  --add-modules javafx.controls,javafx.fxml,java.sql ^
  --win-shortcut ^
  --win-menu ^
  --win-console
```

注意：`--type exe` 需要安装 [WiX Toolset](https://wixtoolset.org/releases/) v3.x，且需要管理员权限。

## 常见问题

### Q：打包后运行报 "JavaFX 相关错误"？
A：确认 `--module-path` 指向的 JavaFX JMODs 版本与项目依赖版本一致（都是 17.0.2）。

### Q：运行后提示数据库连接失败？
A：确认 MySQL 服务已启动，`campus_map` 数据库已初始化（`mysql -u root -p < docs/database/init-database.sql`），且 `database.properties` 中用户名/密码正确。

### Q：app-image 目录太大了？
A：`jpackage` 默认打包整个 JRE，可以改成 `--type app-image --add-modules` 只包含需要的模块来减小体积。当前需要的最小模块集已在上文指定。

### Q：能不能完全免安装，不需要 MySQL？
A：可以，但需要将数据库层从 MySQL 替换为嵌入式 H2 数据库。这是一个中等规模的重构，涉及替换 DAO 层实现和 SQL 方言。如果时间充裕，可以作为后续优化方向。
