# 长安大学校园服务地图系统 - 项目使用说明

## 项目简介

基于 Java + JavaFX + Canvas（OpenStreetMap 瓦片 + Web Mercator 投影）+ MySQL 的校园服务地图系统，提供长安大学渭水校区的地理信息浏览、建筑搜索、路径导航、建筑详情查看、收藏、评论与建筑信息编辑等功能。

## 环境要求

- JDK 17+
- Maven 3.8+
- MySQL 8.0+

## 快速开始

### 1. 初始化数据库

推荐直接执行一体化初始化脚本：

```bash
mysql -u root -p < docs/database/init-database.sql
```

如果你需要分别查看建表和示例数据，也可以参考：

- `docs/database/schema.sql`
- `docs/database/sample-data.sql`

### 2. 配置数据库连接

编辑 `src/main/resources/config/database.properties`，修改为自己的数据库用户名和密码：

```properties
db.username=你的用户名
db.password=你的密码
```

### 3. 编译运行

```bash
# 编译
mvn clean compile

# 运行（JavaFX）
mvn javafx:run

# 或打包后运行
mvn package
java --module-path %JAVA_FX_PATH% --add-modules javafx.controls,javafx.fxml,javafx.web -jar target/campus-map-system-1.0.0.jar
```

### 4. 打包说明

打包步骤详见独立文档：**[docs/软件打包说明.md](软件打包说明.md)**

简要说明当前提供两种方式：
- **app-image 便携目录（推荐）** — 生成一个包含 JDK + JavaFX 运行时的目录，压缩即用
- **exe 安装包** — 使用 jpackage + WiX 生成 Windows 安装程序

> 注意：当前版本依赖 MySQL 8.0+，目标机器上需要 MySQL 服务正常运行。

## 功能说明

### 地图浏览
- 打开程序后自动显示长安大学渭水校区地图
- 鼠标滚轮缩放，拖拽平移
- 建筑使用不同颜色的标注点区分类型
- 点击地图建筑标记后，可在右侧查看建筑详情
- 启动后自动从 OpenStreetMap 下载校园道路数据（后台异步，状态栏显示进度）

### 建筑搜索
- 在右侧搜索面板输入关键词搜索建筑
- 按下拉选择建筑分类过滤
- 点击搜索结果可定位到建筑

### 路径导航

系统提供两种进入导航的方式：

**方式一：从建筑详情**
1. 点击地图上建筑标记，或从搜索结果选中建筑
2. 在右侧详情面板中点击 **[导航到这里]** 按钮
3. 右侧自动切换到导航模式，并已预设目的地建筑
4. 选择起点建筑，点击 **[规划路线]**

**方式二：从搜索面板**
1. 在搜索面板顶部切换到 **"导航"** 标签页
2. 分别选择起点和终点建筑
3. 点击 **[规划路线]**

**导航结果：**
- 地图上绘制蓝色路径线（起点绿色、终点红色标记）
- 右侧导航面板显示起点 → 终点、总距离、步骤列表
- 底部状态栏显示路径总距离
- 可点击 **[退出导航]** 清除路径，或 **[← 返回]** 回到搜索面板

> 路径数据说明：首次启动时系统会自动从 OpenStreetMap 下载校园真实道路数据，下载期间可使用建筑间快捷路径（回退方案）。下载完成后状态栏会提示"路网数据已加载"，后续导航将使用真实道路。

### 建筑编辑
- 管理员编辑建筑后，全体用户可见
- 普通用户编辑建筑后，仅自己可见
- 被管理员锁定的建筑，普通用户不可继续编辑
- 编辑时可直接拖动地图上的红色标记调整坐标

## 代理配置

程序需要通过代理访问外部网络（加载地图瓦片和下载路网数据），默认代理为 `127.0.0.1:7897`。

如需修改代理地址，编辑 `src/main/resources/config/database.properties`：

```properties
proxy.host=127.0.0.1
proxy.port=7897
```

## 设计模式应用（当前版本）

| 模式 | 位置 | 说明 |
|------|------|------|
| 单例模式 (Singleton) | `util/DatabaseConnection.java` | 全局唯一数据库连接 |
| 单例模式 (Singleton) | `util/UserSession.java` | 用户会话管理 |
| 工厂模式 (Factory) | `pattern/factory/BuildingMarkerFactory.java` | 按建筑类型创建不同颜色的标注 |
| 模板方法模式 (Template Method) | `dao/BaseDAO.java` | 通用 CRUD 操作骨架 |
| 观察者模式 (Observer) | `controller/MapController.java` | 地图选中事件通知详情面板更新 |
| 策略模式 (Strategy) | `service/NavigationService.java` | 使用 JGraphT DijkstraShortestPath 实现可替换的最短路径算法 |

## 常见问题

### Q：地图瓦片不显示？
A：确认代理已开启（默认 127.0.0.1:7897），程序需要访问 `tile.openstreetmap.org` 下载瓦片。

### Q：导航路径是直线不是真实道路？
A：首次启动需要从 OpenStreetMap 下载路网数据，请等待状态栏显示"路网数据已加载"后重新规划路线。如果一直提示导入失败，请检查代理和网络连接。

### Q：启动后提示数据库连接失败？
A：确认 MySQL 服务已运行，`database.properties` 中用户名/密码正确，且 `campus_map` 数据库已初始化。

### Q：打包后运行报 JavaFX 相关错误？
A：确认打包时 `--module-path` 指向的 JavaFX JMODs 版本与项目依赖版本一致。
