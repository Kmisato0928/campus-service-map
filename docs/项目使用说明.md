# 长安大学校园服务地图系统 - 项目使用说明

## 项目简介

基于 Java + JavaFX + WebView（Leaflet.js + OpenStreetMap）+ MySQL 的校园服务地图系统，提供长安大学渭水校区的地理信息浏览、建筑搜索、建筑详情查看、收藏、评论与建筑信息编辑等功能。

## 环境要求

- JDK 17+
- Maven 3.8+
- MySQL 8.0+

## 快速开始

### 1. 初始化数据库

推荐直接执行一体化初始化脚本：

```bash
mysql -u root -p < docs/database/init-database.sql
```

如果你需要分别查看建表和示例数据，也可以参考：

- `docs/database/schema.sql`
- `docs/database/sample-data.sql`

### 2. 配置数据库连接

编辑 `src/main/resources/config/database.properties`，修改为自己的数据库用户名和密码：

```properties
db.username=你的用户名
db.password=你的密码
```

### 3. 编译运行

```bash
# 编译
mvn clean compile

# 运行（JavaFX）
mvn javafx:run

# 或打包后运行
mvn package
java --module-path %JAVA_FX_PATH% --add-modules javafx.controls,javafx.fxml,javafx.web -jar target/campus-map-system-1.0.0.jar
```

### 4. 打包说明

打包步骤详见独立文档：**[docs/软件打包说明.md](软件打包说明.md)**

简要说明当前提供两种方式：
- **app-image 便携目录（推荐）** — 生成一个包含 JDK + JavaFX 运行时的目录，压缩即用
- **exe 安装包** — 使用 jpackage + WiX 生成 Windows 安装程序

> 注意：当前版本依赖 MySQL 8.0+，目标机器上需要 MySQL 服务正常运行。

## 功能说明

### 地图浏览
- 打开程序后自动显示长安大学渭水校区地图
- 鼠标滚轮缩放，拖拽平移
- 建筑使用不同颜色的标注点区分类型
- 点击地图建筑标记后，可在右侧查看建筑详情

### 建筑搜索
- 在右侧搜索面板输入关键词搜索建筑
- 按下拉选择建筑分类过滤
- 点击搜索结果可定位到建筑

### 建筑编辑
- 管理员编辑建筑后，全体用户可见
- 普通用户编辑建筑后，仅自己可见
- 被管理员锁定的建筑，普通用户不可继续编辑
- 编辑时可直接拖动地图上的红色标记调整坐标

### 建筑类型与颜色对照

| 类型 | 颜色 | 说明 |
|------|------|------|
| TEACHING | 蓝色 (steel blue) | 教学楼 |
| CANTEEN | 红色 (indian red) | 餐厅 |
| LIBRARY | 绿色 (medium sea green) | 图书馆 |
| DORM | 金色 (goldenrod) | 宿舍 |
| OTHER | 灰色 | 其他建筑 |

## 项目结构

```text
campus-map-system/
├── pom.xml
├── src/main/java/edu/chd/campusmap/
│   ├── Main.java                         # 程序入口
│   ├── model/                            # 数据模型
│   ├── dao/                              # 数据访问层
│   ├── service/                          # 业务逻辑层
│   ├── controller/                       # 控制器层
│   ├── view/                             # JavaFX 视图
│   ├── util/                             # 工具类
│   └── pattern/
│       └── factory/                      # 工厂模式（建筑标记）
├── src/main/resources/
│   ├── config/database.properties        # 数据库配置
│   ├── css/style.css                     # 样式
│   └── map/
│       ├── leaflet.css                   # Leaflet 样式
│       └── leaflet.js                    # Leaflet 脚本
└── docs/
    ├── 项目使用说明.md                    # 本文件
    ├── 项目实现状态.md                    # 项目当前实现情况
    ├── 软件打包说明.md                    # 打包为便携版 / 安装版的步骤
    └── database/
        ├── init-database.sql             # 推荐执行的初始化脚本
        ├── schema.sql                    # 建表脚本
        └── sample-data.sql               # 示例数据
```

## 设计模式应用（当前版本）

| 模式 | 位置 | 说明 |
|------|------|------|
| 单例模式 (Singleton) | `util/DatabaseConnection.java` | 全局唯一数据库连接 |
| 单例模式 (Singleton) | `util/UserSession.java` | 用户会话管理 |
| 工厂模式 (Factory) | `pattern/factory/BuildingMarkerFactory.java` | 按建筑类型创建不同颜色的标注 |
| 模板方法模式 (Template Method) | `dao/BaseDAO.java` | 通用 CRUD 操作骨架 |
| 观察者模式 (Observer) | `controller/MapController.java` | 地图选中事件通知详情面板更新 |
```
