## 一、项目概述

### 1.1 项目背景
本项目是面向对象设计与模式课程的大作业，旨在利用开源地图系统为长安大学师生提供校园地理信息服务。

### 1.2 核心目标
- 提供直观的校园地图浏览体验
- 实现建筑物搜索与路径规划功能
- 支持用户评论、收藏等社交功能
- 展示实时信息（食堂拥挤度、教室占用情况）
- 应用多种设计模式，体现面向对象设计思想

### 1.3 技术选型

| 技术领域 | 选型 | 理由 |
|---------|------|------|
| 编程语言 | Java | 跨平台、成熟稳定、团队熟悉 |
| GUI 框架 | JavaFX | 现代化界面、CSS 样式支持 |
| 地图组件 | OpenStreetMap + JMapViewer | 开源、离线支持、可定制 |
| 数据库 | MySQL/PostgreSQL | 功能完整、SQL 查询能力强 |
| 架构模式 | MVC | 清晰分离、便于团队协作 |
| 构建工具 | Maven | 依赖管理、项目构建 |
| 打包工具 | jpackage | 打包成 Windows 可执行文件 |

## 二、系统架构设计

### 2.1 整体架构：MVC 三层分离

```
┌─────────────────────────────────────────┐
│           View Layer (JavaFX)           │
│  - 登录/注册界面                          │
│  - 主地图界面 (嵌入 JMapViewer)           │
│  - 搜索面板、详情面板、评论面板            │
│  - 用户个人中心                           │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│        Controller Layer (业务控制)       │
│  - UserController (用户管理)             │
│  - MapController (地图交互)              │
│  - SearchController (搜索逻辑)           │
│  - RouteController (路径规划)            │
│  - CommentController (评论管理)          │
│  - FavoriteController (收藏管理)         │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│         Model Layer (数据与业务)         │
│  - User, Building, Comment, Favorite    │
│  - Service 层 (业务逻辑)                 │
│  - DAO 层 (数据访问)                     │
│  - Database (MySQL/PostgreSQL)          │
└─────────────────────────────────────────┘
```

### 2.2 核心模块划分

1. **用户模块** - 用户注册、登录、权限管理（普通用户/管理员）
2. **地图模块** - 地图显示、建筑标注、地图交互
3. **搜索模块** - 关键词搜索、分类筛选
4. **路径规划模块** - 两点间最短路径计算与显示
5. **评论模块** - 用户评论、评分系统
6. **收藏模块** - 收藏建筑、快速访问
7. **实时信息模块** - 定时更新拥挤度等信息

### 2.3 模块间交互

- View 层通过事件触发 Controller 层的方法
- Controller 层调用 Service 层处理业务逻辑
- Service 层通过 DAO 层访问数据库
- Model 层的数据变化通过观察者模式通知 View 层更新

## 三、数据库设计

### 3.1 核心数据表

#### 用户表 (users)
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,  -- BCrypt 加密
    email VARCHAR(100),
    role ENUM('USER', 'ADMIN') DEFAULT 'USER',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 建筑表 (buildings)
```sql
CREATE TABLE buildings (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    category ENUM('TEACHING', 'CANTEEN', 'LIBRARY', 'DORM', 'OTHER'),
    latitude DOUBLE NOT NULL,
    longitude DOUBLE NOT NULL,
    description TEXT,
    image_url VARCHAR(255)
);
```

#### 评论表 (comments)
```sql
CREATE TABLE comments (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    building_id INT NOT NULL,
    content TEXT NOT NULL,
    rating INT CHECK (rating BETWEEN 1 AND 5),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (building_id) REFERENCES buildings(id) ON DELETE CASCADE
);
```

#### 收藏表 (favorites)
```sql
CREATE TABLE favorites (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    building_id INT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY unique_favorite (user_id, building_id),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (building_id) REFERENCES buildings(id) ON DELETE CASCADE
);
```

#### 实时信息表 (realtime_info)
```sql
CREATE TABLE realtime_info (
    id INT PRIMARY KEY AUTO_INCREMENT,
    building_id INT NOT NULL,
    info_type ENUM('CROWD', 'OCCUPANCY') NOT NULL,
    status ENUM('LOW', 'MEDIUM', 'HIGH') NOT NULL,
    time_slot VARCHAR(20),  -- 例如 "12:00-13:00"
    day_of_week INT CHECK (day_of_week BETWEEN 1 AND 7),
    FOREIGN KEY (building_id) REFERENCES buildings(id) ON DELETE CASCADE
);
```

### 3.2 数据关系
- 一个用户可以发表多条评论（1:N）
- 一个用户可以收藏多个建筑（M:N）
- 一个建筑可以有多条评论（1:N）
- 一个建筑可以有多条实时信息记录（1:N）

## 四、设计模式应用

### 4.1 单例模式 (Singleton)
**应用场景**：数据库连接管理、用户会话管理

```java
public class DatabaseConnection {
    private static DatabaseConnection instance;
    private Connection connection;
    
    private DatabaseConnection() {
        // 初始化数据库连接
    }
    
    public static synchronized DatabaseConnection getInstance() {
        if (instance == null) {
            instance = new DatabaseConnection();
        }
        return instance;
    }
}
```

**优势**：确保全局只有一个数据库连接实例，避免资源浪费

### 4.2 工厂模式 (Factory)
**应用场景**：创建不同类型的建筑标注

```java
public interface BuildingMarker {
    void display();
}

public class BuildingMarkerFactory {
    public static BuildingMarker createMarker(String category) {
        switch (category) {
            case "TEACHING": return new TeachingBuildingMarker();
            case "CANTEEN": return new CanteenMarker();
            case "LIBRARY": return new LibraryMarker();
            default: return new DefaultMarker();
        }
    }
}
```

**优势**：解耦标注创建逻辑，便于扩展新类型

### 4.3 观察者模式 (Observer)
**应用场景**：地图状态变化通知各个面板更新

```java
public interface MapObserver {
    void onBuildingSelected(Building building);
}

public class MapController {
    private List<MapObserver> observers = new ArrayList<>();
    
    public void addObserver(MapObserver observer) {
        observers.add(observer);
    }
    
    public void notifyBuildingSelected(Building building) {
        for (MapObserver observer : observers) {
            observer.onBuildingSelected(building);
        }
    }
}
```

**优势**：实现松耦合的事件通知机制

### 4.4 策略模式 (Strategy)
**应用场景**：不同的路径规划算法

```java
public interface RouteStrategy {
    List<Point> calculateRoute(Point start, Point end);
}

public class ShortestPathStrategy implements RouteStrategy {
    @Override
    public List<Point> calculateRoute(Point start, Point end) {
        // Dijkstra 算法实现
    }
}

public class LeastTurnsStrategy implements RouteStrategy {
    @Override
    public List<Point> calculateRoute(Point start, Point end) {
        // 最少转弯算法实现
    }
}
```

**优势**：算法可替换，便于扩展新的路径规划策略

### 4.5 装饰器模式 (Decorator)
**应用场景**：为建筑标注添加不同的视觉效果

```java
public abstract class MarkerDecorator implements BuildingMarker {
    protected BuildingMarker marker;
    
    public MarkerDecorator(BuildingMarker marker) {
        this.marker = marker;
    }
}

public class HighlightDecorator extends MarkerDecorator {
    @Override
    public void display() {
        marker.display();
        addHighlight();  // 添加高亮效果
    }
}
```

**优势**：动态添加功能，不修改原有类

### 4.6 代理模式 (Proxy)
**应用场景**：权限控制，管理员功能访问代理

```java
public class AdminOperationProxy {
    private AdminOperation realOperation;
    private User currentUser;
    
    public void execute() {
        if (currentUser.getRole() == Role.ADMIN) {
            realOperation.execute();
        } else {
            throw new UnauthorizedException();
        }
    }
}
```

**优势**：在不修改原有代码的情况下添加权限检查

### 4.7 模板方法模式 (Template Method)
**应用场景**：数据访问层的通用 CRUD 操作

```java
public abstract class BaseDAO<T> {
    public final void save(T entity) {
        openConnection();
        doSave(entity);
        closeConnection();
    }
    
    protected abstract void doSave(T entity);
    
    private void openConnection() { /* ... */ }
    private void closeConnection() { /* ... */ }
}
```

**优势**：复用通用流程，子类只需实现特定逻辑

## 九、关键技术难点与解决方案

### 9.1 JavaFX 与 Swing 混合使用
**难点**：JMapViewer 是 Swing 组件，需要嵌入 JavaFX

**解决方案**：
```java
SwingNode swingNode = new SwingNode();
JMapViewer mapViewer = new JMapViewer();
SwingUtilities.invokeLater(() -> {
    swingNode.setContent(mapViewer);
});
```

### 9.2 路径规划算法
**难点**：校园道路图建模，最短路径计算

**解决方案**：
- 使用 JGraphT 库建立有向图
- 节点：建筑物、路口
- 边：道路，权重为距离
- 应用 Dijkstra 算法计算最短路径

### 9.3 实时信息的定时更新
**难点**：定时查询数据库并更新 UI

**解决方案**：
```java
ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);
scheduler.scheduleAtFixedRate(() -> {
    Platform.runLater(() -> {
        // 更新 UI
    });
}, 0, 5, TimeUnit.MINUTES);
```

### 9.4 密码安全存储
**难点**：明文存储密码不安全

**解决方案**：
```java
// 注册时加密
String hashedPassword = BCrypt.hashpw(plainPassword, BCrypt.gensalt());

// 登录时验证
boolean isValid = BCrypt.checkpw(plainPassword, hashedPassword);
```

### 9.5 打包成 Windows 可执行文件
**难点**：JavaFX 应用打包复杂

**解决方案**：
```bash
# 使用 jpackage 工具
jpackage --input target/ \
         --name CampusMapSystem \
         --main-jar campus-map-system.jar \
         --main-class edu.chd.campusmap.Main \
         --type exe \
         --win-shortcut \
         --win-menu
```

- 统一命名规范：
  - 类名：大驼峰（UserController）
  - 方法名：小驼峰（getUserById）
  - 常量：全大写下划线（MAX_SIZE）
- 注释规范：
  - 类注释：说明类的职责
  - 方法注释：说明参数、返回值、异常
  - 关键逻辑注释：说明为什么这样做

### 10.2 测试策略
- **单元测试**：JUnit 5，测试 Service 层和 DAO 层
- **集成测试**：测试数据库操作
- **UI 测试**：手动测试关键流程（登录、搜索、路径规划）

  - `main`：稳定版本
  - `dev`：开发版本

- 提交规范：
  - `feat: 添加用户登录功能`
  - `fix: 修复路径规划算法 bug`
  - `docs: 更新数据库设计文档`

## 十一、风险与应对

### 11.1 技术风险
| 风险 | 影响 | 应对措施 |
|------|------|---------|

| 打包后无法运行 | 高 | 提前测试打包流程，准备详细的部署文档 |

### 11.2 进度风险
| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 团队成员技术水平差异 | 中 | 提前技术培训，结对编程 |
| 某个模块延期 | 高 | 预留缓冲时间，关键路径优先 |
| 需求变更 | 中 | 采用渐进式开发，每个阶段都有可交付成果 |
