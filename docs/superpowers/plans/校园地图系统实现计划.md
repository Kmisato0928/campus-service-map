# 长安大学校园服务地图系统 - 实现计划

> 历史过程文档，仅供参考；其中部分技术方案（如 JMapViewer）已与当前项目实现不完全一致。

## 总体策略

Maven 项目，Java + JavaFX + JMapViewer + MySQL，MVC 架构。
5 人团队，渐进式开发，共 4 个阶段，每个阶段 1-2 周。

---

## 阶段 1：项目初始化 + 核心地图功能（第 1 步）

### 第 1.1 步：Maven 项目骨架搭建
**文件**：`pom.xml`
**内容**：
- 配置 JavaFX 17+、JMapViewer、MySQL Connector、JBCrypt、JGraphT 依赖
- 配置 maven-compiler-plugin、javafx-maven-plugin、jpackage 插件

### 第 1.2 步：数据库初始化
**文件**：
- `src/main/resources/config/database.properties`
- `docs/database/schema.sql`
- `docs/database/sample-data.sql`
**内容**：
- schema.sql：创建 users, buildings, comments, favorites, realtime_info 五张表
- sample-data.sql：至少 20 个长安大学校园建筑数据
- database.properties：数据库连接配置

### 第 1.3 步：工具类基础
**文件**：
- `util/DatabaseConnection.java` — 单例模式，数据库连接管理
- `util/ConfigLoader.java` — 配置文件加载
- `util/PasswordUtil.java` — BCrypt 加密工具
- `util/UserSession.java` — 单例模式，用户会话管理

### 第 1.4 步：数据模型
**文件**：
- `model/User.java` — 用户模型
- `model/Building.java` — 建筑模型
- `model/Comment.java` — 评论模型
- `model/Favorite.java` — 收藏模型
- `model/RealtimeInfo.java` — 实时信息模型

### 第 1.5 步：DAO 层 — 模板方法模式
**文件**：
- `dao/BaseDAO.java` — 抽象基类，定义通用 CRUD 模板方法
- `dao/UserDAO.java`
- `dao/BuildingDAO.java`
- `dao/CommentDAO.java`
- `dao/FavoriteDAO.java`

### 第 1.6 步：地图核心功能
**文件**：
- `view/MainMapView.java` — JavaFX 主界面，通过 SwingNode 嵌入 JMapViewer
- `controller/MapController.java` — 地图交互控制
- `service/MapService.java` — 地图业务逻辑
- `pattern/factory/BuildingMarker.java` — 标注接口
- `pattern/factory/BuildingMarkerFactory.java` — 工厂模式，按建筑类型创建不同标注
- `Main.java` — 程序入口

### 第 1.7 步：搜索功能
**文件**：
- `view/SearchPanel.java` — 搜索面板（关键词输入 + 分类下拉）
- `controller/SearchController.java`
- `service/SearchService.java`

### 阶段 1 验证
- [ ] 项目可编译运行
- [ ] 地图正常显示长安大学区域
- [ ] 建筑标注可见，点击显示基本信息
- [ ] 搜索可按名称和分类筛选
- [ ] 数据库表已创建，数据已导入

## 阶段 2：用户系统 + 路径规划

### 第 2.1 步：用户系统
**文件**：
- `view/LoginView.java` — 登录界面
- `view/RegisterView.java` — 注册界面
- `controller/UserController.java`
- `service/UserService.java`
- `pattern/proxy/AdminOperationProxy.java` — 代理模式，权限控制

### 第 2.2 步：路径规划
**文件**：
- `controller/RouteController.java`
- `service/RouteService.java`
- `pattern/strategy/RouteStrategy.java` — 策略接口
- `pattern/strategy/ShortestPathStrategy.java` — 最短路径策略（Dijkstra）
- `pattern/strategy/LeastTurnsStrategy.java` — 最少转弯策略

### 阶段 2 验证
- [ ] 用户可以注册和登录
- [ ] 密码 BCrypt 加密存储
- [ ] 管理员和普通用户权限区分
- [ ] 选择两个建筑后可计算并显示路径

## 阶段 4：实时信息 + 美化 + 打包

### 第 4.1 步：实时信息模块
**文件**：
- `service/RealtimeInfoService.java` — ScheduledExecutorService 定时更新
- 扩展 DetailPanel 显示拥挤度/占用状态
- 数据由预设时间表和随机因子生成

### 第 4.2 步：界面美化
**文件**：
- `src/main/resources/css/style.css` — 全局样式
- FXML 布局优化（资源文件）
- 交互反馈（动画、提示框）

### 第 4.3 步：代码规范检查
- 使用 CheckStyle 执行阿里代码规范
- 修复所有不规范代码

### 第 4.4 步：打包
- 使用 jpackage 打包为 Windows 可执行文件
- 测试安装包功能完整

### 阶段 4 验证
- [ ] 实时信息按时间段正确显示
- [ ] 界面美观统一
- [ ] 代码通过 CheckStyle 检查
- [ ] 可生成 Windows exe 安装包
