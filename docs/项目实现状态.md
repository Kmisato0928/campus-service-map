## 二、地图功能详细说明

### 2.1 技术方案
- JavaFX `Canvas` 自定义渲染（非 WebView）
- OpenStreetMap 瓦片地图（Web Mercator 投影）
- 支持多级缩放（12-19），平滑滚动平移
- AnimationTimer 实现平滑定位动画
- 异步加载瓦片图片（不阻塞 UI）

### 2.2 地图交互
- **显示**：长安大学渭水校区，默认中心 [34.3705, 108.8985]，缩放 16
- **建筑标记**：24 个建筑，按类型分色（教学蓝、食堂红、图书馆绿、宿舍金、其他灰）
- **点击标记**：通知 Java 端选中事件 → 右侧显示详情面板
- **编辑后实时更新**：在详情面板编辑建筑信息保存后，地图标记自动刷新
- **拖动编辑**：编辑建筑时可直接拖动红色标记修改经纬度
- **搜索定位**：搜索面板选中建筑 → 地图平滑定位到该建筑
- **缩放保持中心**：鼠标滚轮缩放时以鼠标位置为中心点保持不变

### 2.3 搜索面板功能
- 关键字搜索（模糊匹配建筑名称）
- 分类筛选（全部 / 教学楼 / 餐厅 / 图书馆 / 宿舍 / 其他）
- 结果列表点击 → 地图定位
- **导航模式**：切换至导航标签页 → 选择起点/终点建筑 → 规划路线

### 2.4 导航功能
- **路网数据**：启动时从 OpenStreetMap Overpass API 自动下载校园真实道路数据
- **双图架构**：
  - 优先使用 OSM 路网（JGraphT 加权图 + Dijkstra 最短路径）
  - 数据未就绪时回退到建筑间连接图（附近 4 个建筑，500 米内）
- **路径显示**：蓝色折线绘制在地图上，起点绿色标记、终点红色标记
- **导航面板**：显示起点 → 终点、总距离、步骤列表
- **异步导入**：后台线程下载路网数据，状态栏实时显示进度，完成后自动加载

### 2.5 建筑详情
- 名称 + 类别 + 描述
- 收藏/取消收藏按钮
- 导航到这里按钮
- 编辑按钮（管理员始终可见；普通用户仅在建筑未被管理员锁定时可见）
- 用户评论列表 + 点赞 + 删除（作者/管理员）
- 发表评论输入框 + 评分选择

## 三、数据库状态

数据库 `campus_map` 当前已支持 9 张核心表：

| 表名 | 用途 |
|------|------|
| `users` | 用户（admin, zhangsan, lisi），密码为 BCrypt 加密 |
| `buildings` | 长安大学渭水校区建筑（含 `edited_by_admin` 权限标记） |
| `comments` | 用户评论与评分 |
| `favorites` | 用户收藏记录 |
| `realtime_info` | 模拟实时信息（教室占用、食堂拥挤度） |
| `user_building_overrides` | 用户个人建筑覆盖（普通用户编辑仅自己可见） |
| `comment_likes` | 评论点赞（每人每评论限一次） |
| `path_nodes` | OSM 路网节点（经纬度 + 可选名称 + 关联建筑） |
| `path_edges` | OSM 路网边（节点连接 + 距离 + 道路名称） |

> 说明：程序启动时会自动检测并创建缺失的表，无需手动执行 SQL。

## 四、用户操作流程

### 4.1 启动 → 登录/注册
```text
启动程序 → 登录界面
         ├── 输入用户名密码 → 登录成功 → 主地图界面
         └── 点击"立即注册" → 注册界面 → 注册成功 → 返回登录
```

### 4.2 地图浏览
```text
主地图界面
├── 中间：Canvas 地图（鼠标滚轮缩放、拖拽平移）
├── 顶部栏：系统标题 + 用户名 + [个人中心] [退出] 按钮
├── 右侧面板：搜索面板（默认），可切换为详情面板 / 导航面板
└── 底部：状态栏（显示 OSM 导入进度、操作提示等）
```

### 4.3 搜索建筑
```text
输入关键字 / 选择分类 → 点击搜索
    → 结果列表显示匹配建筑
    → 点击列表项 → 地图定位到该建筑 + 右侧切换为详情面板
```

### 4.4 建筑详情
```text
详情面板显示：
├── 建筑名称 + 类别
├── 建筑描述
├── [收藏/取消收藏] 按钮
├── [导航到这里] 按钮 → 切换到导航模式并预设目的地
├── [编辑] 按钮（管理员始终可见；普通用户仅在建筑未被管理员锁定时可见）
├── 用户评论列表（每条评论包含：用户名 + 星级评分 + 发布时间 + 内容）
│   ├── [点赞/已赞] 按钮 + 点赞数（每人限点一次）
│   └── [删除] 按钮（评论作者或管理员可见）
├── 发表评论输入框 + 评分选择 + [发表] 按钮
└── [← 返回搜索] 按钮
```

### 4.5 路径导航
```text
方式一：从详情面板
  建筑详情 → [导航到这里] → 切换到导航模式，预设目的地
  → 选择起点建筑（默认定位当前位置）→ [规划路线]
  → 地图显示蓝色路径 + 导航面板显示距离和步骤

方式二：从搜索面板
  搜索面板 → 切换到"导航"标签页
  → 选择起点 + 终点 → [规划路线]
  → 地图显示蓝色路径 + 导航面板

导航面板：
├── 起点 → 终点
├── 总距离
├── 步骤列表
├── [← 返回] 按钮 → 返回搜索/详情面板
└── [退出导航] 按钮 → 清除路径并返回
```

### 4.6 编辑建筑（权限说明）
```text
管理员编辑：更新 buildings 表 → 清除所有用户个人覆盖 → 标记为管理员已编辑（全局生效）
  └── 编辑后普通用户看到管理员版本，且无法再次编辑此建筑

普通用户编辑：保存到 user_building_overrides 表（仅自己可见）
  └── 管理员编辑后，用户的个人覆盖会被清除，恢复为全局版本

编辑对话框字段：名称 / 类别 / 纬度 / 经度 / 描述
  ├── [保存] → 数据持久化 + 地图标记实时更新
  └── [取消] → 放弃修改
```

### 4.7 个人中心
```text
点击顶部栏 [个人中心] → 个人中心页面
├── 用户信息（用户名 + 角色）
├── 我的收藏（建筑名称列表）
├── 我的评论（建筑名 + 评分 + 内容）
├── [返回地图] 按钮
└── [退出登录] 按钮
```
