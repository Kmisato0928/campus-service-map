## 二、地图功能详细说明

### 2.1 技术方案
- JavaFX `WebView` 内嵌网页
- `Leaflet.js` 1.9.4 渲染 OpenStreetMap 瓦片地图
- CSS/JS 文件通过 `loadResource()` 内联到 HTML，无需外部加载
- Java ↔ JavaScript 双向桥接（`JSObject` + `JavaBridge`）

### 2.2 地图交互
- **显示**：长安大学渭水校区，中心 [34.3740, 108.9100]，缩放 15
- **建筑标记**：24 个建筑，按类型分色（教学蓝、食堂红、图书馆绿、宿舍金、其他灰）
- **点击标记**：弹出信息气泡（名称 + 分类），通知 Java 端选中事件 → 右侧显示详情面板
- **编辑后实时更新**：在详情面板编辑建筑信息保存后，地图标记自动刷新
- **拖动编辑**：编辑建筑时可直接拖动红色标记修改经纬度
- **搜索定位**：搜索面板选中建筑 → 地图自动定位并打开气泡

### 2.3 搜索面板功能
- 关键字搜索（模糊匹配建筑名称）
- 分类筛选（全部 / 教学楼 / 餐厅 / 图书馆 / 宿舍 / 其他）
- 结果列表点击 → 地图定位

## 三、数据库状态

数据库 `campus_map` 当前已支持 7 张核心表：

| 表名 | 用途 |
|------|------|
| `users` | 用户（admin, zhangsan, lisi），密码为 BCrypt 加密 |
| `buildings` | 长安大学渭水校区建筑（含 `edited_by_admin` 权限标记） |
| `comments` | 用户评论与评分 |
| `favorites` | 用户收藏记录 |
| `realtime_info` | 模拟实时信息（教室占用、食堂拥挤度） |
| `user_building_overrides` | 用户个人建筑覆盖（普通用户编辑仅自己可见） |
| `comment_likes` | 评论点赞（每人每评论限一次） |

> 说明：当前版本推荐直接执行 `docs/database/init-database.sql` 完成建表与示例数据初始化；程序启动时也会尝试自动补齐新增表结构。

## 四、用户操作流程

### 4.1 启动 → 登录/注册
```text
启动程序 → 登录界面
         ├── 输入用户名密码 → 登录成功 → 主地图界面
         └── 点击“立即注册” → 注册界面 → 注册成功 → 返回登录
```

### 4.2 地图浏览
```text
主地图界面
├── 左侧/中间：Leaflet 地图（可缩放、拖拽）
├── 顶部栏：系统标题 + 用户名 + [个人中心] [退出] 按钮
├── 右侧面板：搜索面板（默认）
└── 底部：状态栏
```

### 4.3 搜索建筑
```text
输入关键字 / 选择分类 → 点击搜索
    → 结果列表显示匹配建筑
    → 点击列表项 → 地图定位到该建筑 + 右侧切换为详情面板
```

### 4.4 建筑详情
```text
详情面板显示：
├── 建筑名称 + 类别
├── 建筑描述
├── [收藏/取消收藏] 按钮
├── [编辑] 按钮（管理员始终可见；普通用户仅在建筑未被管理员锁定时可见）
├── 用户评论列表（每条评论包含：用户名 + 星级评分 + 发布时间 + 内容）
│   ├── [点赞/已赞] 按钮 + 点赞数（每人限点一次，不可重复）
│   └── [删除] 按钮（评论作者或管理员可见）
├── 发表评论输入框 + 评分选择 + [发表] 按钮
└── [← 返回搜索] 按钮
```

### 4.5 编辑建筑（权限说明）
```text
管理员编辑：更新 buildings 表 → 清除所有用户个人覆盖 → 标记为管理员已编辑（全局生效）
  └── 编辑后普通用户看到管理员版本，且无法再次编辑此建筑

普通用户编辑：保存到 user_building_overrides 表（仅自己可见）
  └── 管理员编辑后，用户的个人覆盖会被清除，恢复为全局版本

编辑对话框字段：名称 / 类别 / 纬度 / 经度 / 描述
  ├── [保存] → 数据持久化 + 地图标记实时更新
  └── [取消] → 放弃修改
```

### 4.6 个人中心
```text
点击顶部栏 [个人中心] → 个人中心页面
├── 用户信息（用户名 + 角色）
├── 我的收藏（建筑名称列表）
├── 我的评论（建筑名 + 评分 + 内容）
├── [返回地图] 按钮
└── [退出登录] 按钮
```
